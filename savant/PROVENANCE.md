# SAVANT Provenance v0.3

Every evidence record can preserve:

- source URL or citation note
- source title
- publisher / author
- publication date
- retrieval timestamp
- exact quotation / excerpt
- research note / context
- source class: PRIMARY / SECONDARY / UNKNOWN
- stance: SUPPORTS / CONTRADICTS / CONTEXT

These are recorded fields, not automatically verified facts. In particular, publisher, author, publication date, source class and stance are user-entered metadata in the current local prototype.

Retrieval time is generated by EDGE when evidence is attached. Source links using HTTP(S) open with `noopener noreferrer`.

The purpose is reconstructability: future-you should be able to inspect not merely a conclusion, but the evidence record that informed it.
