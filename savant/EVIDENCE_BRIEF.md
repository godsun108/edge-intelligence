# SAVANT Evidence Brief v0.5

SAVANT can now produce an **extractive evidence brief** for the selected claim.

The brief reorganizes only records already stored in the local evidence map into:
- SUPPORTS
- CONTRADICTS
- CONTEXT
- UNRESOLVED QUESTIONS

Each evidence entry retains its displayed source title/citation and source class.

This is deliberately not generative synthesis. It does not infer a winner, truth value, confidence score, consensus, completeness, or causal explanation. “None recorded” means only that the local collection contains no entry in that category.

This creates a safe foundation for later evidence-aware synthesis: first make the evidence map inspectable, then add machine analysis without erasing provenance or uncertainty.
