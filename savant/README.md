# SAVANT v0.1 — Evidence Map

SAVANT begins as a local-first evidence workspace.

A user can create a claim or research question, select it, and attach evidence records labeled **SUPPORTS**, **CONTRADICTS**, or **CONTEXT**. Each record preserves the source/citation note and attachment time.

SAVANT does not calculate a truth score, vote evidence into a conclusion, or treat the number of supporting records as proof. Stance is an explicit organizational label, not an automated verdict.

Current storage is browser localStorage under `edge.savant.v1`. This is a foundation for later primary-source retrieval, source metadata, quotations, unresolved questions, contradiction detection, and evidence-aware synthesis.
