# Memory Pulse

TIME MACHINE v0.7 adds a descriptive activity summary over local SENSE captures.

It reports capture counts for rolling 24-hour, 7-day, and 30-day windows, with counts broken down by capture type. The calculation uses only original local timestamps and types.

The pulse must not be interpreted as mood, productivity, importance, health, intent, engagement quality, or psychological state. It answers only: **how many things did I deliberately capture in these windows, and what types were they?**

This creates a longitudinal primitive without pretending that activity telemetry explains the person.
