# Memory Map

TIME MACHINE v0.6 adds a navigable local memory map.

Selecting **MAP** makes the chosen capture the seed and displays its current RELATED MEMORY candidates as neighboring nodes. Selecting a neighbor re-centers the map on that capture.

The map is a retrieval interface, not a knowledge graph. Edges mean only that the current transparent similarity function found textual overlap plus optional same-type/route boosts. They do not assert causation, identity, chronology, agreement, or factual relationship.

All computation remains local in the browser and no capture text is transmitted to a remote graph or embedding service.
