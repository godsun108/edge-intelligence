# TIME MACHINE Horizons

TIME MACHINE v0.2 adds explicit age horizons to deliberate resurfacing:

- ANY TIME
- 24H+
- 7D+
- 30D+

The selected horizon is a user constraint, not an importance score. If no capture satisfies it, the interface says so instead of silently substituting a newer memory.

Resurfacing remains stochastic within the eligible local set. It never rewrites a capture, changes its timestamp, or promotes it automatically.
