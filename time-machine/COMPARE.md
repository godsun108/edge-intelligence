# Memory Compare

TIME MACHINE v0.5 lets the user deliberately select two captures and inspect them side by side.

The comparison shows only recorded fields: original text, capture type, route, timestamps, and the calculated elapsed days between captures.

EDGE explicitly does **not** infer that the later memory represents progress, regression, contradiction, completion, or a change in belief. Those interpretations require the human or a future evidence-aware analysis layer.

This creates a trustworthy comparison primitive before adding higher-level longitudinal analysis.
