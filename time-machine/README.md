# TIME MACHINE v0.1

TIME MACHINE begins as a deliberate resurfacing layer over SENSE memory.

**RESURFACE** selects one prior capture and places it into the existing searchable-memory view. Captures older than 24 hours are preferred when available. It does not infer importance, generate meaning, or automatically promote anything.

The current primitive is:

**capture → retain → retrieve → resurface → human review → optional promote**

This is intentionally small. Future versions can add date ranges, related-memory retrieval, project grouping and semantic search while preserving provenance and the distinction between remembered information and current truth.
