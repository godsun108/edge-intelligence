# Memory Threads

TIME MACHINE v0.4 can assemble a chronological thread around a selected SENSE capture.

A thread contains the selected seed plus the current RELATED MEMORY candidates, ordered by their original capture timestamps. The interface labels the result **MACHINE-ASSEMBLED · CHRONOLOGICAL**.

A thread is a view, not a new fact. EDGE does not claim that the entries describe one project, causal chain, narrative, or intention merely because the retrieval layer grouped them. Original capture text and timestamps remain unchanged.

This creates the next primitive:

**memory → related candidates → chronology → human interpretation**
