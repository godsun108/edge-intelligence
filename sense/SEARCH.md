# Searchable Memory

SENSE v0.5 makes captured memory retrievable instead of merely chronological.

The local interface supports:
- text search across capture text, type, and route
- type filtering for IDEA, OBJECT, OBSERVATION, and TASK
- up to 50 matching results in the working view
- existing deliberate promotion controls on matching captures

Search is performed entirely in the browser over the user's local SENSE store. No query or capture is sent to a remote search service.

This is the first TIME MACHINE primitive: **capture → retain → retrieve → promote**.
