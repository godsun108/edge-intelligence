# SENSE → EDGE Promotion

SENSE v0.4 adds a deliberate bridge from capture memory into the EDGE attention layer. Captures remain passive memory until the user chooses **PROMOTE**.

- TASK promotes to WATCHING.
- Other capture types promote to SAVED.
- Promotion records the capture and timestamp in the local EDGE inbox state.
- Nothing is automatically promoted merely because a heuristic classifier routed it.

SENSE also summarizes local capture counts by type. This is descriptive memory intelligence, not behavioral inference.

This preserves the central separation: **capture is not commitment; observation is not decision.**
