# Universal Capture

SENSE v0.2 introduces one universal text input. A lightweight, deterministic router classifies a capture as IDEA, OBJECT, TASK, or OBSERVATION and attaches an intended destination: MEMORY, KEEP, EDGE, or SENSE. Explicit category buttons override routing and are recorded as explicit rather than heuristic.

Routing is intentionally transparent and reversible. It is not an AI claim about what the user meant; it is a convenience classifier. Captures remain local to the browser.

## Native bridge target
A future iOS companion can expose the same Capture action through Apple's App Intents so it can participate in Shortcuts, Siri, Spotlight and supported hardware/system experiences. The web prototype does not claim native device access.
