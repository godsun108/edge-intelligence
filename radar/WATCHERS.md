# RADAR WATCHER SPEC

A watcher is a small adapter that converts a legitimate public source into EDGE observations. Watchers must preserve provenance, stable IDs when supplied, observation/retrieval time, source URL, structured data and tags.

Watchers do not decide whether an item is good. Rules score explicit matches and preserve reasons. The briefing suppresses zero-relevance changes. Sensitive/private criteria belong in a private deployment, never this public repository.

## Next adapter families
Public grants and funding notices; public auctions/surplus; public property/parcel data where terms permit; official releases and open datasets; user-selected price feeds with lawful APIs.
