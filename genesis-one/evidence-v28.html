All scenarios and candidate gates are predeclared. Selection uses a one-sided Wilson 95% upper error bound ≤1% in EACH validation scenario, at least 100 accepted per scenario. These bounds are descriptive and not corrected for selection, multiple tests, or dependence. If none qualify, the diagnostic candidate is still evaluated on fresh held-out tasks, but is NOT approved. Evidence-consistent policies retain 3, 5, or 8 plausible candidate programs, choose discriminative probes, and RECOMPUTE the same MAE or trimmed-MAE score from all observations after every probe. A probe that contradicts the current leader blocks acceptance. The H family is not added to the candidate grammar. This experiment uses four follow-ups before verification, so it is not an equal-measurement-budget comparison with early-stopping controls. The K family is test-only, never used for selection.
