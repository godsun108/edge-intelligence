Can learned mathematical programs be retrieved from incomplete and noisy observations without sacrificing correctness?

200 tasks/trial. Fixed fit grid: 6 points. A missing observation is excluded; noise changes an observed y by +1 or -1. Every strategy receives identical corrupted observations. Validation uses a separate six-point noiseless oracle available only to the simulator.

Three strategies: indexed exact memory (lookup only if all six observations are present and exact), approximate verified memory (rank learned programs by fit residual, verify the best two), and non-learning (scan initial library and synthesis grammar each task). All strategies use the same residual-based fallback search. An independent noiseless oracle validates proposed solutions; this is a controlled simulation, not a deployable real-world verification system. Candidate comparisons, oracle validations, index probes, and memory writes are counted separately as abstract units; ranking/sorting work is not fully captured in the abstract metric, but is included in measured strategy execution time. Approximate search is not claimed optimal.
