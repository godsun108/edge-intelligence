Methods: fixed-order investigation; active disagreement (maximize weighted predicted variance among plausible candidates); active random (seeded random location without replacement). All use the same conservative acceptance criterion: heuristic score ≥0.62, margin ≥0.5 and ≥3 nonmissing observations. Candidate universe has 176 pre-enumerated programs, plus 10% held-out out-of-distribution tasks. No hidden target identity enters the decision procedure. Each measurement request costs one unit even if missing. Candidate comparisons and disagreement evaluations are counted separately; abstract cost sums comparisons, location evaluations and requested samples. Browser timing is noisy. This is a synthetic experiment, not general-purpose scientific discovery.
