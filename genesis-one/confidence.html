Genesis ONE v14 · Confidence Without an Oracle

Can Genesis make calibrated accept / investigate / abstain decisions using imperfect observations, with hidden truth revealed only to the evaluator?

200 tasks/trial. Every method receives the same initial data and the same pre-generated extra observations. The decision engine cannot inspect target identity, true outputs, or evaluator labels.

Strategies: forced-guess nearest fit; cautious nearest fit with adaptive investigation; cautious retrieval with previously accepted memory. Scores are heuristic, not calibrated probabilities. A false accept is an incorrect final program; abstentions are not counted as correct. Program candidates come from a fixed 176-program universe (154 base + 22 grammar), and every in-distribution task has a valid candidate. Extra observations cost one unit each, including missing measurements; fitting candidate comparisons cost one each; memory ranking costs one per remembered candidate. No ground-truth oracle is used in the decision logic. Calibration and runtime must be assessed after export. A deliberately small out-of-distribution set is included by sampling x^5+b and x^2-2x+b programs; these are not in the candidate library.
