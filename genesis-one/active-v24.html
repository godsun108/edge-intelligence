All scenarios and candidate gates are predeclared. Selection uses a one-sided Wilson 95% upper error bound ≤1% in EACH validation scenario, at least 100 accepted per scenario. These bounds are descriptive and not corrected for selection, multiple tests, or dependence. If none qualify, the diagnostic candidate is still evaluated on fresh held-out tasks, but is NOT approved. Active policy ranks candidate probe locations by disagreement against the eight best alternative programs using only observations available at decision time; it stops at enough matches, a mismatch, or budget. Missing probes cost one request. The fixed v22 comparator requests three; v23 sequential comparator requests up to three. Candidate-prediction checks count toward abstract cost. Synthetic only.
