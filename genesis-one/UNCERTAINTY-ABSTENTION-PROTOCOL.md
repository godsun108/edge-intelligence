# Uncertainty abstention experiment

Frozen v35 is unchanged. Compare shadow acceptance requiring discrete-noise ranking to agree with v35 and the winner to lead the runner-up by at least 2 or 4 penalty points. Predeclared synthetic development suite: seed=2500001, count=200, seedCount=4 (4,000 tasks). Report correct accepted, wrong accepted, abstentions and correct rejections. These are development results, not an independent holdout.

Repeated measurements are NOT part of this experiment: the generator only provides pre-generated probes. Reusing a probe observation is not independent sampling. An independent repeat measurement generator would need to be built and tested separately, with all requests accounted for.
